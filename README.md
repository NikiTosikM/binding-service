# Микросервис "Телефон-Адрес"

## Запуск проекта
- создаем файл .env в корне проекта (можно скопировать из .env.template)
- создаем образ приложения - docker build . -t contact-app:latest
- запускаем приложение - docker-compose up --build
- **Pydantic** - валидация данных

## Архитектура
- **FastAPI** - REST API
- **Redis** - хранилище ключ-значение
- **Docker** - контейнеризация
- **Pydantic** - валидация данных

## Эндпоинты

### 1. `GET /api/contacts/{phone}`
Получить адрес по номеру телефона
- **200**: `{"address": "ул. Пушкина, д.1"}`
- **404**: Телефон не найден

### 2. `POST /api/contacts`
Создать новую связку телефон-адрес
- **201**: Запись создана
- **409**: Телефон уже существует
- **Тело**: `{"phone": "79275052132", "address": "ул. Пушкина, д.1"}`

### 3. `PUT /api/contacts/{phone}`
Обновить адрес для телефона
- **200**: Адрес обновлён
- **404**: Телефон не найден
- **Тело**: `{"address": "новый адрес"}`

### 4. `DELETE /api/contacts/{phone}`
Удалить запись
- **204**: Запись удалена
- **404**: Телефон не найден
